# SmartKKB

Group-expense tracker as a Java Swing desktop app — organize people into partner groups, log expenses, and split them by percentage. Comes with a promo site.

## What's in here

- `SmartKKB.java` — app source (`javac SmartKKB.java` to build)
- `SmartKKB.zip` / `SmartKKB.png` — packaged app and screenshot
- `index.html` + member pages — promo site, open `index.html`

Data persists to `smartkkb_data.dat` next to the jar.
